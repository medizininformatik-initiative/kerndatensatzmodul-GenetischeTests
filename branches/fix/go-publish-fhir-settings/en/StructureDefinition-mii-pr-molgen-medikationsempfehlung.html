Resource Profile: MII PR MolGen Medikationsempfehlung

Official URL: https://www.medizininformatik-initiative.de/fhir/ext/modul-molgen/StructureDefinition/medikationsempfehlung Version: 2027.0.0-ballot.rc1
Active as of 2026-09-03 Computable Name: MII_PR_MolGen_Medikationsempfehlung

Das Profil dieser Task Ressource dient dazu, auf der Grundlage der genetischen Ergebnisse medikamanetöse Maßnahmen vorzuschlagen.

Description

The profile of this Task resource serves to propose medication-based measures on the basis of the genetic results.

The profile is derived from the profile Medication Recommendation of the HL7 Genomics Reporting Implementation Guide.

Profile

FHIR element Logical data set
Task Interpretation.Empfehlungen
