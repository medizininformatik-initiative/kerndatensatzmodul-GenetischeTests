Resource Profile: MII PR MolGen Anforderung genetischer Test

Official URL: https://www.medizininformatik-initiative.de/fhir/ext/modul-molgen/StructureDefinition/anforderung-genetischer-test Version: 2027.0.0-ballot.rc2
Active as of 2026-09-04 Computable Name: MII_PR_MolGen_AnforderungGenetischerTest

Der Laborauftrag oder die Anfrage, die die Durchführung des genetischen Tests auslöst.

Description

The laboratory order or the request that triggers the performance of the genetic test.

The request can also state one or more known symptoms via the reasonReference element as 'Phenotypic Features', which are profiled in GA4GH's Phenopackets IG.
